# Mac Setup with Nix

This repository contains my personal Mac setup using Nix and nix-darwin. It provides a reproducible way to configure a new Mac with my preferred settings and applications.

## Prerequisites

- macOS (tested on macOS Ventura and later)
- Administrator access

## Getting Started

Follow these steps to set up a new Mac using this configuration:

1. Install Nix using the Determinate Systems installer:
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install
   ```

2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/mac-setup.git
   cd mac-setup
   ```
